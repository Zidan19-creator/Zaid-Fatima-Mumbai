# Zaid & Fatima — Wedding Invitation

A mobile-first blue-and-ivory wedding invitation with an illustrated opening, tap-anywhere gate animation, Nikah and Shaadi scenes, a scratch-to-reveal message, and family and designer credits.

## Celebrations

- Nikah: 24 December, 6:00 PM
- Shaadi: 25 December, 7:00 PM
- Venue: Hotel Sea Princess, Juhu

## Files

- `index.html`: the complete website, styles and interactions
- `assets/`: local illustrations, fonts and font license files

Open `index.html` in a browser to preview. No installation or build is required.

For GitHub Pages, publish the `main` branch from the repository root in **Settings → Pages**. Repository visibility and GitHub plan determine Pages availability.
